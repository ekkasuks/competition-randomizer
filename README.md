# ระบบสุ่มและโหวตการแข่งขัน (Competition Randomizer & Voting)

เว็บแอปสำหรับจัดการแข่งขันของโรงเรียน ครบทุกขั้นตอน: สร้างรายการแข่งขันหลายรายการ → เพิ่มทีม/สมาชิก/รูป → สุ่มจัดคิวทีมพร้อมเอฟเฟกต์ → เปิดโหวต → คำนวณอันดับ → ประกาศผล

หน้าเว็บเป็น static host บน **GitHub Pages** ส่วนการโหวต (หลายเครื่อง) ใช้ **Google Apps Script + Google Sheets** เป็น backend

---

## โครงสร้างไฟล์

```
competition-randomizer/
├── index.html          หน้าแรก/เมนู
├── admin.html          หน้าแอดมิน (จัดการรายการ ทีม ผู้โหวต เปิด-ปิดโหวต)
├── draw.html           หน้าสุ่มจัดคิวทีม (สปอตไลต์ + คอนเฟตติ + เสียง)
├── vote.html           หน้าผู้โหวต (เปิดจากลิงก์ที่แอดมินส่งให้)
├── result.html         หน้าประกาศผล (โพเดียม + โหมดประกาศเต็มจอ)
├── css/style.css
├── js/
│   ├── config.js       ★ ตั้งค่า GAS_URL และ ADMIN_KEY ที่นี่
│   ├── api.js          ชั้นข้อมูล (localStorage / Google Sheets)
│   ├── ui.js  fx.js    ตัวช่วย UI / เสียง+คอนเฟตติ
│   ├── admin.js  draw.js  vote.js  result.js
└── gas/Code.gs         โค้ด Google Apps Script (backend)
```

---

## โหมดการทำงาน 2 แบบ

ระบบสลับ backend อัตโนมัติจากค่าใน `js/config.js`:

| GAS_URL | โหมด | เก็บข้อมูลที่ | เหมาะกับ |
|---|---|---|---|
| เว้นว่าง `""` | ทดลอง | localStorage ในเครื่องนั้น | ลองใช้ / ครูคนเดียว |
| ใส่ URL /exec | ใช้จริง | Google Sheets | โหวตหลายเครื่องพร้อมกัน |

> การโหวตจริง (ส่งลิงก์ให้คนอื่นโหวตจากมือถือ) **ต้องใช้โหมด Google Sheets** เพราะ localStorage แยกกันคนละเครื่อง

## ขั้นตอนที่ 1 — ตั้งค่า Backend (Google Apps Script)

1. เปิด https://sheets.google.com สร้างสเปรดชีตใหม่ 1 ไฟล์ (ตั้งชื่ออะไรก็ได้)
2. เมนู **ส่วนขยาย (Extensions) → Apps Script**
3. ลบโค้ดเดิมทิ้ง แล้ววางเนื้อหาไฟล์ `gas/Code.gs` ทั้งหมด
4. (ถ้าต้องการเปลี่ยนรหัสแอดมิน) แก้บรรทัด `"banmai2569"` ในฟังก์ชัน `setup()` ให้เป็นรหัสที่ต้องการ
5. บันทึก (💾) แล้วเลือกฟังก์ชัน **`setup`** จากเมนูด้านบน กด **Run** หนึ่งครั้ง
   - อนุญาตสิทธิ์ (Authorize) เมื่อระบบถาม → เลือกบัญชี → Advanced → Go to project → Allow
   - จะได้ชีต `Competitions`, `Teams`, `Voters`, `Votes` สร้างให้อัตโนมัติ
6. กด **Deploy → New deployment**
   - Select type (⚙️) → **Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
   - กด **Deploy** → คัดลอก **Web app URL** (ลงท้าย `/exec`)

## ขั้นตอนที่ 2 — เชื่อมหน้าเว็บกับ Backend

เปิด `js/config.js` แล้วแก้ 2 บรรทัด:

```js
GAS_URL: "https://script.google.com/macros/s/xxxxx/exec",  // URL จากขั้นตอนที่ 1
ADMIN_KEY: "banmai2569",   // ให้ตรงกับที่ตั้งใน setup()
```

## ขั้นตอนที่ 3 — ขึ้น GitHub Pages

1. สร้าง repository ใหม่บน GitHub อัปโหลดไฟล์ทั้งหมด (ยกเว้นโฟลเดอร์ `gas/` จะเก็บไว้หรือไม่ก็ได้ ไม่กระทบการทำงาน)
2. **Settings → Pages → Build and deployment → Source: Deploy from a branch → `main` / root → Save**
3. รอสักครู่ จะได้ลิงก์ `https://<username>.github.io/<repo>/`
4. เปิด `.../admin.html` เพื่อเริ่มใช้งาน

## วิธีใช้งาน

**แอดมิน** (`admin.html`) — กรอกรหัสแอดมิน → สร้างรายการแข่งขัน → กด "จัดการ" → เพิ่มทีม/สมาชิก/รูป → ใส่รายชื่อผู้โหวต → กด "เปิดโหวต" → คัดลอกลิงก์ส่งให้ผู้โหวต

**สุ่ม** (`draw.html`) — เลือกรายการ → กด "สุ่มทีม" ทีละครั้ง ระบบจดจำลำดับคิว เหมาะฉายขึ้นจอโปรเจกเตอร์

**ผู้โหวต** (`vote.html`) — เปิดลิงก์ → เลือกชื่อตนเอง → เลือกทีมที่ 1/2/3 → ส่ง (แก้ไขได้จนกว่าแอดมินจะปิดโหวต)

**ประกาศผล** (`result.html`) — เลือกรายการ → ดูโพเดียม/คะแนน → กด "ประกาศผลแบบเต็มจอ" เพื่อเฉลยที่ 3 → 2 → 1

**การคิดคะแนน:** ผู้โหวตให้คะแนนแต่ละทีม 1–10 · สรุปเป็น **คะแนนรวม** และ **คะแนนเฉลี่ย** · จัดอันดับด้วยคะแนนเฉลี่ย (เสมอ → ดูจำนวนผู้โหวตและคะแนนรวม)

## หมายเหตุ

- รูปทีมใช้เป็น **ลิงก์ URL** (เช่น ลิงก์รูปจาก Google Drive แบบเปิดสาธารณะ หรือ imgur) ระบบไม่อัปโหลดไฟล์
- รหัสแอดมินเป็นการกันเบื้องต้น ไม่ใช่ระบบความปลอดภัยระดับสูง
- รองรับหลายรายการแข่งขันพร้อมกัน สุ่ม/โหวตแยกกันแต่ละรายการ
- ถ้าเปลี่ยนโค้ด Apps Script ภายหลัง ต้อง **Deploy → Manage deployments → แก้ไข → New version** เพื่อให้ URL เดิมอัปเดต
